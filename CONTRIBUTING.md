# Contributing to Automated Resume Screening Tool

**Author & Project Lead:** Akash Das  
**Project Type:** Academic & Student Portfolio Project  

Thank you for your interest in the **Automated Resume Screening Tool**!

## Guidelines
1. **Academic Integrity & Attribution**: Always maintain author credit for Akash Das.
2. **Modular Code Structure**: Keep business logic inside `src/`, entry points in `app.py`, and automated tests in `tests/`.
3. **Synthetic Data Only**: Never submit or commit real people's personal resumes or sensitive personal information. All test resumes must be completely synthetic.
4. **Responsible AI & Fairness**: Scores represent illustrative textual similarity metrics, not certified evaluations of human competence. Do not add mechanisms for automated candidate rejection.
5. **Testing**: Ensure any additions include matching unit tests in `tests/`.
