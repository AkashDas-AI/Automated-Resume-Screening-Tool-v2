## 3. Engineering & Governance Standards

All implementations adhere strictly to the following core tenets:
- **Mathematical Determinism:** Full floating-point precision with reproducible 4-tier tie-breaking.
- **Candidate Privacy:** Strict anonymization of Personally Identifiable Information (PII).
- **Accessibility:** 100% WCAG 2.2 AA contrast compliance across Light and Dark themes.
- **Ethical AI:** Mandatory human-in-the-loop review policy; automated rejection is architecturally prohibited.
